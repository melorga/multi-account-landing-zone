# Security Policy

## Supported Versions

Only the `main` branch receives security updates.

## Reporting a Vulnerability

If you believe you have found a security vulnerability in this
repository, **please do not open a public issue**. Instead, report it
privately via GitHub's [Private Vulnerability Reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing/privately-reporting-a-security-vulnerability)
feature on this repository, or email the maintainers.

We aim to acknowledge reports within 5 business days and to provide a
remediation timeline within 10 business days.
